# Friendly Feuds

**Friendly Feuds** is an app for tracking competitive matches and stats between friends, family, or rivals. 
Create “feuds,” register foes, and log each skirmish to see who comes out on top.

See the live app **[here](https://fravl.github.io/friendly-feuds/)**.

---

## Features

- 📝 **Create Feuds**: Start a new rivalry, name your feud, and add your competitors.
- 🎮 **Log Skirmishes**: Register match results (scores) for all foes.
- 🏆 **Automatic Stats**: See most wins, highest single score, longest win streaks, and more!
- 📈 **History**: View a grid of all past skirmishes and individual scores.

---

## Getting Started

### **Run locally**

```bash
git clone https://github.com/fravl/friendly-feuds.git
cd friendly-feuds
flutter pub get
flutter run -d chrome
```
